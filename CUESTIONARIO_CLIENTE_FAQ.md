# Cuestionario de Validación de Preguntas Frecuentes (FAQ) — SODAGRO

Este cuestionario recoge las 15 preguntas estratégicas integradas en la web. Está preparado para que el cliente (SODAGRO) valide o ajuste datos operativos específicos si lo considera oportuno.

---

### Bloque 1: Gestión Integral de Fincas y PAC
1. **¿Quién responde ante la Junta en caso de inspección o penalización de la PAC?**
   - *Respuesta web actual:* El titular de la explotación es el responsable legal, pero SODAGRO actúa como representante técnico autorizado, registrando todo en plazo y defendiendo el expediente en inspecciones y alegaciones.
   - *Pregunta para el cliente:* ¿Ofrecéis póliza o garantía específica de tramitación sin penalización si el cliente entrega la documentación a tiempo?

2. **Para propietarios que viven fuera o herederos de comunidades de bienes, ¿con qué frecuencia se envían los informes de campo?**
   - *Respuesta web actual:* Presupuesto previo, partes diarios, fotos y liquidación al céntimo con la almazara.
   - *Pregunta para el cliente:* ¿Preferís especificar si los informes son mensuales, por campaña o tras cada labor ejecutada?

3. **¿Cuál es el protocolo exacto para la visita técnica agronómica inicial sin compromiso?**
   - *Respuesta web actual:* Visita presencial a la finca, diagnóstico y presupuesto cerrado sin coste ni compromiso.
   - *Pregunta para el cliente:* ¿Hay algún límite de kilómetros desde Cabra para la visita gratuita inicial?

---

### Bloque 2: Contratación, Tarifas y Ámbito Operativo
4. **¿Cuál es el modelo de cobro habitual en recolección con paraguas?**
   - *Respuesta web actual:* Por horas con mínimo de jornada para labores mecanizadas, o precio cerrado por hectárea en fincas homogéneas.
   - *Pregunta para el cliente:* ¿Tenéis una tarifa orientativa por hora de vibro-paraguas (ej. 65-75 €/h) o preferís dejarlo siempre como "presupuesto a medida tras ver la finca"?

5. **¿Qué provincias y comarcas cubrís habitualmente?**
   - *Respuesta web actual:* Toda la provincia de Córdoba (Campiña y Subbética: Lucena, Baena, Montilla, Priego), Jaén, Sevilla, norte de Málaga y Granada.
   - *Pregunta para el cliente:* ¿Deseáis destacar alguna otra comarca o municipio preferente?

6. **¿Cuál es la superficie mínima para que os desplaceis a una finca pequeña?**
   - *Respuesta web actual:* No hay mínimo cerrado; se agrupan parcelas cercanas en la misma zona o se aplica un mínimo por salida pactado.
   - *Pregunta para el cliente:* ¿Tenéis un mínimo de horas o hectáreas establecido por salida?

7. **¿Con qué aseguradora tenéis la póliza de Responsabilidad Civil de maquinaria?**
   - *Respuesta web actual:* Seguro de responsabilidad civil en regla para cubrir cualquier contingencia.
   - *Pregunta para el cliente:* (Dato interno) ¿Queréis mencionar la cobertura o mantenerlo genérico?

---

### Bloque 3: Recolección Mecanizada y Maquinaria
8. **¿Qué medidas tomáis para proteger el tronco del olivo con el vibrador?**
   - *Respuesta web actual:* Regulación de presión, tacos de goma de contacto protegidos, tiempos controlados de vibración y descarte previo de árboles con daños o huecos.
   - *Pregunta para el cliente:* ¿Algún detalle técnico sobre la marca/tipo de pinza (ej. pinza orbital, tacos especiales)?

9. **¿En qué pendientes máximas u olivares de varios pies operáis con paraguas?**
   - *Respuesta web actual:* En olivares centenarios de varios pies valoramos si conviene paraguas o vibrador con mantones; en pendiente trabajamos a favor del terreno priorizando seguridad.
   - *Pregunta para el cliente:* ¿Tenéis límite de pendiente porcentual para el paraguas?

10. **¿Hacéis contratos para labores sueltas de campaña?**
    - *Respuesta web actual:* Sí, se pueden contratar labores individuales (recolección, poda, abonado) sin atarse a un contrato anual.

11. **¿Recolectáis almendra y pistacho con el mismo equipo de paraguas?**
    - *Respuesta web actual:* Sí, paraguas y vibradores adaptados con lonas y frecuencias específicas para aceituna, almendra y pistacho.

---

### Bloque 4: Vivero Oficial, Calendario y Nuevas Plantaciones
12. **¿Cuál es el número de registro oficial ROPVEG de vuestro vivero?**
    - *Respuesta web actual:* Vivero oficial inscrito en el ROPVEG con pasaporte fitosanitario oficial de la Junta de Andalucía libre de Xylella y verticilosis.
    - *Pregunta para el cliente:* (Dato recomendado) ¿Podemos añadir el número de registro ROPVEG en el pie de página para darle aún mayor autoridad legal ante inspectores y clientes?

13. **¿Qué variedades tenéis en stock habitual?**
    - *Respuesta web actual:* Olivar (Picual, Hojiblanca, Arbequina), almendro y pistacho.

14. **¿Qué garantía exacta ofrecéis en la reposición de marras para plantaciones llave en mano?**
    - *Respuesta web actual:* Reposición de marras estipulada por contrato en primera campaña (cubriendo fallo de planta/arraigo, excluyendo sequía extrema o falta de riego del cliente).
    - *Pregunta para el cliente:* ¿Suele ser hasta un 2% - 5% de marras o reposición del 100% de plantas no arraigadas con riego adecuado?

15. **¿Con cuánta antelación recomendáis reservar la máquina de recolección y la planta de vivero?**
    - *Respuesta web actual:* 3-4 semanas antes para máquina de recolección; 2-3 meses antes para plantones de vivero.
